## 七、内容去重闸门（2026-11-16 追加）

需求：每日推荐不要重复；观点可以更正，但不得把旧内容原样搬上来。

### 机制

1. **相似度**：中文按二元组 Jaccard（去标点空白后），同文 1.000、异题 <0.05；判定分三档：
   - `copy`（照搬级）：摘要相似 ≥0.62，或标题相似 ≥0.72 且摘要 ≥0.45；
   - `topic`（同话题）：摘要 ≥0.42 或标题 ≥0.50；
   - `none`：其余。
2. **查重语料**：取同板块最近 21 篇的标题、摘要、要点；局势板块额外做**事件级**查重（事件标题相似 ≥0.6 即判为讲过）。
3. **重写回路**：命中后把被命中的旧文摘要喂回模型，附硬性要求（不照搬；若确有新进展必须写清「相比上次新增了什么」；没变化就换角度），最多重试 3 次，取重复度最低的一稿。
4. **选题账本** `topic_usage`：
   - 书籍：同一学科的一本书讲过一次就跳过，用完一轮才允许重讲（且必须换角度）；
   - 前沿 AI：同一个 GitHub 仓库不重复讲；
   - 历史账本可用 `scripts/seed-topic-ledger.ts` 从既有文章回填。
5. **允许更正**：判定为 `topic` 而非 `copy` 时，模型可以再讲同一件事，但正文必须写出新增了什么——这正是「观点可以更正」的口径。

### 验收

| 项 | 结果 |
|---|---|
| 去重引擎自检 | 13 项断言全过（同文 1.000 / 异题 0.039 / 照搬判 copy / 新话题判 none / 事件级识别 / 指令生成） |
| 真实链路演练 | 强制重生成「全球局势」：第 1 稿命中 `topic 0.51`（与当天旧稿同题）→ 自动重写 → 第 2 稿判 `none`；新稿 5 条事件中 4 条为全新 |
| 账本回填 | 书籍种子 1 条、仓库 5 条，回填脚本对书名做了归一化匹配 |
| 类型检查 | `tsc --noEmit` 零报错 |

### 已知限制

1. 相似度是词面层面的：若模型用完全不同的措辞复述同一个判断，可能落在 `none` 档而漏检；已用「同板块近 21 篇 + 事件级 + 选题账本」三层兜底。
2. 书籍账本每个学科只有 6 个候选，讲完一轮后重讲同一本书时依赖提示词要求换角度，不再有硬保证。
3. 去重重试每次会多消耗一次大模型调用（最多 3 次），单板块耗时上限约 3 分钟。
