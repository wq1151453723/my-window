你的烦恼，可能不是你的错

很多人把失业、婚恋焦虑、育儿崩溃当成自己不够努力，独自消化。米尔斯在《社会学的想象力》里提出一个关键区分：个人烦恼发生在个人经历里，公共议题则和制度安排有关。当一种困境在很多人身上同时出现，它可能就不再是性格问题。这本书教人把处境放回社会结构中看，既不甩锅，也不自责。理解这一点，能帮普通人更清醒地做选择、更少地内耗。

一次 chat/completions 请求的完整旅程

你每天发出的那个 POST /v1/chat/completions，看起来只是把一段 JSON 丢出去再收回来，但请求头里的鉴权、请求体里的 messages、stream 开关、system prompt，每一处都对应模型内部的一个环节。本讲把一次调用拆成四段：网关鉴权与路由、消息拼装成上下文、模型逐 token 生成、以及流式返回时 SSE 如何把 token 一段段推回来。讲完你会知道为什么字段顺序会影响结果、为什么流式能降低等待感却不降低总耗时、以及哪些字段出错时现象会出现在哪一层。

把老项目一点点换成 Rust 的检查工具
